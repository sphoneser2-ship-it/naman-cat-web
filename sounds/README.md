# 고양이 소리 파일 (선택)

비워 두면 게임이 소리를 직접 합성해서 냅니다.
녹음한 소리를 쓰려면 이 폴더에 mp3/ogg 파일을 넣고 `sounds.json`에 종류별로 적으세요.

```json
{ "meow": ["meow1.mp3", "meow2.mp3"], "mew": ["kitten1.mp3"], "happy": ["happy1.mp3"] }
```

종류: mew(아기 냥), meow(냐옹), long(길게), chirp(짧게 냥?), low(불만), happy(기분 좋음), trill(르릉), yawn(하품).
직접 녹음했거나 상업적 이용이 허락된(CC0 등) 소리만 넣으세요.
